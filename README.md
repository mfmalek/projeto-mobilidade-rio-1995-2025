## Resumo Executivo
Este projeto analisa a evolução temporal do movimento médio diário de passageiros no Município do Rio de Janeiro ao longo de três décadas (1995–2025), abrangendo os modais **rodoviário** (ônibus), **ferroviário** (metrô, trem e bondes), **hidroviário** (barcas) e **aeroviário**. Utilizando um pipeline determinístico em Python, o estudo examina o impacto de políticas públicas, grandes eventos e choques exógenos (como a pandemia de COVID-19) na matriz de transporte modal carioca.
